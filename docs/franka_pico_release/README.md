# Franka/Pico Release documentation

This directory documents the Release-owned adaptation layer. RLinf upstream
documentation remains in the framework documentation tree.

- `installation.md`: host and environment prerequisites.
- `operations.md`: supported collection flow and safety rules.
- `dependencies.md`: external vendor and hardware dependencies.
- `source-provenance.md`: approved source baselines and remote roles.
- `upstream-sync.md`: repeatable RLinf synchronization and validation process.
- `continuous-gripper.md`: supported trigger-based Robotiq control semantics.
